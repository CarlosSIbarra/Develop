# ارسم والعب (SketchPlay)

نموذج أولي للعبة تحول رسمة على الورق إلى مرحلة ثنائية الأبعاد.

## مفتاح الألوان

- الأسود: منصات صلبة
- الأصفر: عملات
- الأزرق: هدف النهاية
- الأخضر: نقطة بداية اللاعب

التطبيق يعمل دون إنترنت، ويستخدم كاميرا الهاتف أو اختيار صورة من الجهاز. بعد التحليل تُستخدم الصورة نفسها كخلفية وتُضاف إليها الحركة والتصادم.

## البناء

يتضمن المستودع سير عمل GitHub Actions باسم **Build APK**. كل دفع إلى `main` يبني `app-debug.apk` ويرفعه كـ artifact باسم `sketch-play-debug-apk`.
