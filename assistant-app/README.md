# رفيقي (Rafiki Assistant)

مساعد صوتي عربي خفيف يعمل بلا مفاتيح API وبلا خادم خاص. يستخدم خدمة التعرف على الكلام المثبتة في الهاتف عند الضغط على زر الميكروفون، ثم يرد بصوت Android TextToSpeech باللغة العربية.

## ما يفعله الإصدار الأول

- ينتظر حتى ينتهي المستخدم من الكلام ثم يرد.
- وضع محادثة صوتية مستمرة: بعد الرد الصوتي يبدأ الاستماع تلقائيًا، ويتوقف عند الضغط على زر الإيقاف.
- يفهم التحيات، السؤال عن الحال، الشكر، الوداع، الوقت والتاريخ.
- يشرح قدراته عند قول: «ماذا تستطيع؟».
- يحفظ اسم المستخدم محليًا عند قول: «اسمي ...».
- يجيب عن أوامر المساعدة والنكتة والتحفيز وبعض العمليات الحسابية البسيطة.
- يحتوي على أزرار اقتراحات سريعة وواجهة محادثة بفقاعات مستديرة أخف على الشاشة.
- يعمل كذلك بالكتابة عندما لا يتوفر التعرف الصوتي.

لا يوجد اتصال مباشر بواجهة API أو مفتاح سري داخل التطبيق. جودة تحويل الصوت إلى نص تعتمد على محرك التعرف العربي الموجود في الهاتف، وجودة الصوت تعتمد على حزمة الصوت العربية المثبتة.
